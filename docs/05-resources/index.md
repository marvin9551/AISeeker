## 内容分类

| 分类 | 说明 | 入口 |
| --- | --- | --- |

## 收录原则

- 优先官方来源，信息真实可验证。
- 标注适用人群（开发者 / 非技术用户）。
- 免费资源优先，付费资源明确标注。

## 如何贡献

- 新增资源请到 [curated-links](./curated-links) 按格式补充。
- 失效链接请提交 Issue 或 PR 移除，保持导航干净。
