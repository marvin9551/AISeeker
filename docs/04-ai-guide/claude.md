# Claude 使用技巧

> 面向非技术用户。Claude 在长文本理解、写作与代码场景口碑较好，本文记录实用技巧。

## 基础用法

- 长文档处理：上传长文档，让 Claude 总结要点、提炼表格、按章节提问。
- 写作场景：文章润色、改写、翻译，可要求「先给大纲，再展开写」。
- 代码场景：粘贴报错信息让 AI 排查，粘贴代码段让 AI 解释或优化。

## 高频场景

### 长文档精读
- 上传报告后问：「用三句话概括全文」「列出所有关键数据」「第 X 部分的逻辑是什么」。

### 内容创作
- 让 Claude 生成多版标题、开头，从中挑选，再逐段打磨。

### 翻译与本地化
- 要求「保持原文语气，符合中文表达习惯，专业术语给出双语对照」。

## 与其他工具搭配

- 需要最新网络信息时，可先用搜索引擎查好，再把内容贴给 Claude 分析。
- 需要图片识别时，视工具能力选择 ChatGPT 或 Claude，见[工具对比](./tool-comparison)。

## 注意事项

- 与 ChatGPT 类似：敏感信息人工核对，不传隐私数据。
- 各工具的免费/付费额度不同，价格在变化，以官方为准。
