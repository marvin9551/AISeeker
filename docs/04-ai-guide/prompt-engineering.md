# 提示词入门

> 提示词（Prompt）是人和 AI 沟通的方式。掌握下面几个套路，回答质量立刻提升。

## 万能四要素：角色 + 任务 + 背景 + 要求

好的提问 = 四个要素尽量都给到。

```
【角色】你是……（资深文案 / 十年经验的财务专家 / 耐心的初中老师）
【任务】帮我……（写一段 / 总结一下 / 翻译成）
【背景】相关上下文（对象是谁、用途是什么、已经有哪些材料）
【要求】格式与约束（字数、语气、分点、避免什么、给几个版本）
```

### 对比示例

> 差的提问：帮我写一封邮件。
>
> 好的提问：
> 你是一名职场沟通专家。帮我写一封邮件，向客户解释项目延期一个月，并表达歉意和后续补救计划。
> 要求：语气诚恳但不卑微，200 字以内，分三段，最后给出一个可以立即预约的沟通时间。

## 五个常用技巧

1. **给示例（Few-shot）**：先给一个「输入-输出」例子，模型更容易模仿格式。
2. **要求它分步思考**：复杂问题可以加上「请先列出步骤，再逐步解答」。
3. **追问迭代**：不满意就说「太长了，精简到 100 字」「语气再正式一些」。
4. **让它先反问**：不确定需求时，可以要求「先问我 3 个澄清问题再回答」。
5. **限定输出格式**：要求 Markdown、表格、编号列表，方便直接使用。

## 常见失败与对策

| 问题 | 对策 |
| --- | --- |
| 回答太宽泛 | 给更多背景，限定范围 |
| 格式不对 | 明确指定格式，并给一个示例 |
| 编造事实 | 关键信息交叉核对，要求标注不确定之处 |
| 一次说不清 | 拆成多个小问题逐个问 |
