# 工具对比与选型

> 主流 AI 工具怎么选？没有「最好的工具」，只有「适合你的场景」。
> 注意：各工具功能与定价变化很快，本文只给选型思路，请以官方最新信息为准。

## 按需求选工具

| 你的需求 | 建议关注的方向 |
| --- | --- |
| 日常问答、写作、翻译 | 通用对话助手（ChatGPT、Claude、Kimi、豆包等） |
| 最新网络信息 | 带联网搜索能力的对话助手或 AI 搜索引擎 |
| 图片理解 / 多模态 | 支持图像输入的模型 |
| 长文档处理 | 上下文窗口大、文档能力强的模型 |
| 本地部署 / 数据保密 | 开源模型 + 本地或私有化部署 |
| 低代码搭应用 | Dify、Coze、n8n 等平台 |

## 选型检查清单

1. **能力**：是否支持你需要的能力（联网、图片、文件、长文本）？
2. **价格**：免费额度多少？订阅费多少？按 token 计费还是订阅制？
3. **隐私与合规**：数据如何处理？是否允许上传敏感信息？
4. **生态**：有没有插件、API、与常用软件的集成？
5. **稳定性**：是否频繁变更？社区评价如何？

## 工具速览

> 只列选型维度，具体定价和功能请查阅官方文档。

| 工具 | 适合场景 | 关注点 |
| --- | --- | --- |
| ChatGPT | 通用对话、多模态、生态完整 | 订阅价格、联网搜索 |
| Claude | 写作、长文本、代码 | 上下文窗口、长文档能力 |
| Kimi / 豆包 等国内产品 | 中文场景、易用性 | 数据合规、特定能力 |
| 开源模型 | 私有化、深度定制 | 部署成本、硬件要求 |
