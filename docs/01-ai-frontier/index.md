## 一条前沿信息的记录格式

每条信息建议按下面的模板记录，方便社区维护和读者追溯：

```markdown
### [标题，一句话说明这是什么]

- **日期**：YYYY-MM-DD
- **类型**：模型发布 / 论文 / 开源项目 / 工具 / 资讯
- **一句话介绍**：它解决了什么问题，有什么亮点。
- **对开发者意味着什么**：要不要跟进？用在什么场景？
- **对非技术用户意味着什么**：普通人能怎么用上？
- **来源**：[链接或出处]
```

## 贡献指南

- 不确定信息真实性时，在 PR 描述里注明来源。
