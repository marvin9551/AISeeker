# RAG 与检索

> RAG 是「必考 + 高频」方向，几乎每个 AI 岗位都会问。重点考察对完整链路的理解。

## 链路类

- 讲一下 RAG 的完整流程？每个环节的作用是什么？（`入门`）
- 文档切片（chunk）怎么切？chunk size 怎么定？（`进阶`）
- 什么是混合检索（稀疏 + 稠密）？为什么要做重排（rerank）？（`进阶`）
- 如何解决「检索到但答错」的问题？（`进阶`）

## 工程类

- 向量数据库和传统数据库有什么区别？怎么选型？（`进阶`）
- 数据更新后索引如何保持同步？（`进阶`）
- RAG 系统的效果怎么评估？RAGAS 指标有哪些？（`进阶`）
- 长文档场景如何做？GraphRAG、Agentic RAG 解决什么问题？（`深入`）

## 场景题

- 给一个「企业内部知识库问答」需求，你会怎么设计系统？（`进阶`）
- 检索质量差，你从哪些方面排查？（`进阶`）
