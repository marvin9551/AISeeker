# 基础概念

> 机器学习 / 深度学习 / 大模型基础。这类问题常作为第一轮的「暖场题」，
> 考的是**概念是否清晰**，而不是背得多熟。

---

### 什么是 token？为什么大模型按 token 计费？

- **难度**：入门
- **考察点**：大模型的基本输入输出单位
- **参考答案要点**：token 是模型处理文本的最小单位，可能是单词、子词或字符。模型以 token 为单位读取和生成内容，因此按 token 计费。中文一个汉字通常对应 1-2 个 token。
- **追问**：为什么长文本成本高？如何压缩 token 用量？

---

### 什么是上下文窗口（context window）？超出会怎样？

- **难度**：入门
- **考察点**：大模型的能力边界
- **参考答案要点**：上下文窗口是模型一次能处理的 token 数量上限。超出后通常被截断，或依赖框架做裁剪/压缩。窗口越大，能放进去的资料越多，但成本也越高。
- **追问**：长文本处理还有哪些方案（滑动窗口、RAG、摘要）？

---

### 什么是温度（temperature）？调高会怎样？

- **难度**：入门
- **考察点**：采样策略
- **参考答案要点**：temperature 控制输出随机性，越高越发散/有创意，越低越确定/保守。代码生成一般用低温度，头脑风暴可用高温度。
- **追问**：top-p 和 temperature 有什么区别？

---

### 什么是幻觉（hallucination）？怎么缓解？

- **难度**：进阶
- **考察点**：大模型的已知缺陷与工程应对
- **参考答案要点**：幻觉指模型生成看似合理但错误/虚构的内容。缓解手段：给足可靠上下文（RAG）、强制引用来源、降低温度、提示词约束、后置校验、微调。
- **追问**：RAG 为什么能缓解幻觉？能不能完全消除？

---

### 什么是 embedding？什么是向量？

- **难度**：入门
- **考察点**：表示学习基础
- **参考答案要点**：embedding 把文本映射成高维数值向量，语义相近的文本在向量空间中距离近。向量是 embedding 的结果，用于相似度检索、聚类等。
- **追问**：embedding 模型怎么选？怎么衡量两个向量相似？
