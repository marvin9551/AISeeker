# 工程实践与编程

> 系统设计、算法与编程、部署运维相关题目。这部分通常与通用后端面试重叠。

## 系统设计类

- 设计一个高并发的大模型 API 网关：限流、鉴权、缓存怎么做？（`进阶`）
- 如何为多租户设计模型路由与成本计量？（`深入`）
- 一个 AI 应用的完整架构：前端、网关、模型服务、向量库、监控（`进阶`）

## 算法与编程类

- 经典 LeetCode 与手写题（高频，按目标公司准备）
- 手写一个简单的 RAG 检索函数（`进阶`）
- 手写 Agent 工具调用的解析与分发逻辑（`进阶`）

## 部署运维类

- 模型服务怎么部署？GPU 显存不够怎么办？（`进阶`）
- 如何监控模型质量下降（数据漂移、效果回归）？（`深入`）
- 生产环境如何做灰度与回滚？（`进阶`）
