# 大模型 LLM

> 大模型原理、训练与微调、推理优化、评测相关题目。

## 原理类

- 什么是 Transformer？注意力机制解决了什么问题？（`入门`）
- 什么是预训练？什么是 next-token prediction？（`入门`）
- 什么是自回归生成？解码策略有哪些（贪心、Beam Search、采样）？（`进阶`）
- 为什么说大模型具备「涌现能力」？体现在哪些方面？（`进阶`）

## 微调类

- SFT、LoRA、QLoRA 分别是什么？什么时候用微调，什么时候用 RAG？（`进阶`）
- 什么是 RLHF？和 SFT 有什么区别？（`深入`）
- 微调数据怎么构造？数据质量如何评估？（`进阶`）

## 推理与部署类

- 什么是 KV Cache？为什么能加速推理？（`进阶`）
- 什么是量化（INT8/INT4）？为什么部署时常用？（`进阶`）
- 如何降低大模型推理的延迟与成本？（`进阶`）

## 评测类

- 怎么评估一个模型的真实能力？benchmark 有哪些局限？（`进阶`）
- 如何为业务场景构建自己的评估集？（`进阶`）
