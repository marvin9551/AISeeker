# 面试题库

> 按主题与难度组织的真题与解析。每条题目的目标都是帮你看清**面试官在考什么**。

## 题目组织方式

- 每题包含：**问题 → 考察点 → 参考答案（要点） → 追问方向**
- 按主题分：基础概念 / 大模型 / RAG / Agent / 工程实践
- 难度标注：`入门` / `进阶` / `深入`

## 题库目录

| 主题 | 内容 | 入口 |
| --- | --- | --- |
| 基础概念 | 机器学习、深度学习、Transformer 常识 | [fundamentals](./fundamentals) |
| 大模型 LLM | 原理、微调、推理、评测 | [llm](./llm) |
| RAG 与检索 | 检索链路、向量库、评估 | [rag](./rag) |
| Agent 与工具调用 | 框架、MCP、可靠性 | [agents](./agents) |
| 工程实践与编程 | 系统设计、算法题、部署运维 | [engineering](./engineering) |

## 如何贡献题目

- 按上面的格式补充题目，标注来源（公司/面经链接）可选。
- 不确定答案时，只写「考察点」和「思路」，不要编造标准答案。
- 详见仓库根目录的 `CONTRIBUTING.md`。
