# Agent 与工具调用

> Agent 是当前最热的方向之一。重点考察：工具调用机制、规划能力、可靠性与成本控制。

## 概念类

- 什么是 Agent？Agent 和普通 Chat 应用的本质区别是什么？（`入门`）
- 什么是 ReAct？为什么「思考-行动-观察」能提升能力？（`进阶`）
- 什么是 Function Calling / Tool Use？底层是怎么实现的？（`进阶`）
- 什么是 MCP？它解决了什么问题？（`进阶`）
- 单 Agent 和多 Agent 怎么选？（`进阶`）

## 可靠性类

- Agent 卡在死循环怎么办？（`进阶`）
- 如何控制 Agent 的成本（token 消耗）？（`进阶`）
- Agent 调外部工具出错时如何处理？如何做重试与降级？（`进阶`）
- 如何让 Agent 的输出可观测、可审计？（`进阶`）
- Agent 的安全边界怎么设？（`深入`）

## 场景题

- 做一个「能自主完成某流程」的 Agent，你的架构设计？（`进阶`）
- 工具返回的数据不可信，怎么校验？（`进阶`）
