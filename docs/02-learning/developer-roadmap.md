# 开发者路线图

> 面向程序员：目标是能独立完成 AI 应用开发，并应对技术面试。
> 按 8-12 周设计，可灵活调整。

## 阶段总览

| 阶段 | 主题 | 核心产出 |
| --- | --- | --- |
| 第 1 周 | 基础概念与大模型 API | 跑通第一个 Chat 应用 |
| 第 2-3 周 | 提示词工程 | 完成一个结构化提示词项目 |
| 第 4-5 周 | RAG 应用开发 | 做一个带知识库的问答系统 |
| 第 6-7 周 | Agent 开发 | 做一个能调用工具/API 的 Agent |
| 第 8-9 周 | 微调与评估 | 跑通一次微调，建立评估体系 |
| 第 10-12 周 | 生产化与求职 | 完善简历项目，准备面试 |

## 第 1 周：基础概念

- 理解大模型工作原理的通俗解释（token、上下文窗口、温度）
- 掌握至少一个厂商 API 的调用（对话、流式输出、函数调用）
- 产出：一个命令行或网页版聊天机器人

## 第 2-3 周：提示词工程

- 学习结构化提示词：角色、任务、约束、示例（Few-shot）
- 了解常见的失败模式：幻觉、忽略指令、输出不稳定
- 产出：一个用于特定场景的提示词模板库

## 第 4-5 周：RAG 应用开发

- 掌握文档加载 → 切片 → 向量化 → 检索 → 生成的完整链路
- 学会选择向量库与 embedding 模型
- 产出：一个能引用来源的知识库问答系统

## 第 6-7 周：Agent 开发

- 理解 ReAct 循环、工具调用（Function Calling / Tool Use）
- 掌握一个 Agent 框架（LangGraph、OpenAI Agents SDK 等）
- 了解 MCP 与多智能体协作
- 产出：一个能查天气、查数据库或执行搜索的 Agent

## 第 8-9 周：微调与评估

- 了解 SFT、LoRA/QLoRA、RLHF/DPO 的概念区别
- 学会构建评估集，量化模型与 RAG 系统的效果
- 产出：一份微调实验报告 + 评估脚本

## 第 10-12 周：生产化与求职

- 学习部署、监控、成本控制、安全与合规
- 对照[面试题库](../03-interview/)查漏补缺
- 产出：一份简历级项目 + 高频题整理
